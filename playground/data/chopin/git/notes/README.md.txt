# Notes

A small notes app for iOS and Android, built with Expo.

## Development

```sh
npm install
npm start
```

## Layout

| Path | What lives there |
| --- | --- |
| `src/store/` | In-app note state |
| `src/sync/` | Sends edits to the notes API |
| `src/db/` | On-device SQLite database |
| `src/search/` | Local full-text search |
