A document's machine choice is an icon-only picker (MachineButton) just left of Build plan or the decisions capsule in the desktop title bar, and in the phone top bar; it covers both the Planner and builds. Chat gets no picker, and the document's title menu has no Machine item. The sidebar's Machines menu sets the default machine.
