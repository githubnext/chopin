Research diagnostics already use 13 of the job validator’s 16 fields (including elapsedMs). Keep failure metadata to three fields; JSON-RPC codes may be negative, so encode validated numeric codes in the bounded local classification string. Never copy MCP messages, names, bodies, URLs, headers or data into diagnostics.
