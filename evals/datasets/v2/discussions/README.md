# Adapted development discussions

These seven development cases summarize public GitHub issues, pull-request comments,
and discussions. Each event is a new paraphrase, not the source comment text. The
`source.url` and each event's `url` identify the original; IDs, actors, timestamps,
reply relationships, and cutoff times retain the historical source structure.
`visibleAt` records the later edited version's visibility where it differs from
creation time. A cutoff includes events whose `visibleAt ?? createdAt` is at or
before its `at` time.

The [GitHub Terms of Service](https://github.com/github/site-policy/blob/main/Policies/github-terms/github-terms-of-service.md)
allow viewing and forking public content through GitHub, but do not clearly grant
permission to republish every third-party issue or discussion comment in this
repository. This dataset therefore contains attributed, source-grounded
adaptations. It contains input only, with no evaluation labels or expected
outputs. The original historical registry remains unchanged in `../../registry.json`.
