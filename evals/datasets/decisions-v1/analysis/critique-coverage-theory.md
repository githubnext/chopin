# Critique: coverage. Does the questions design support the decisions builders actually make?

Scope: the design as agreed in review/SPEC.md, review/consult.md (§1 layers, §8 flows F1–F8, §9 hard calls), review/critique-pages.md (unified page) and canvas/project/TuneExamples.dc.html. This is a theory-first pass: decisions/raw/ is still empty, so every frequency claim below is a prediction to be tested against decisions/SCHEMA.md records, not a finding.

**Confidence key.** _High_: established, I would stake the recommendation on it. _Moderate_: well-grounded reasoning or a source I am fairly sure of, but I have not checked the exact wording. _Low_: informed guess; the dataset should decide it.

**One structural caveat before anything else (high).** The corpus is collected from public threads (RFCs, proposals, issues, meeting notes) and only admits decisions that were _debated_ (SCHEMA "Only decisions that were actually DEBATED…"). That oversamples committees, consensus and long threads, and it structurally _excludes_ the decisions this persona makes most: undebated calls between one person and an agent, and calls an agent makes silently in code. Hypotheses below are therefore phrased with a stratum (for example `participants.count ≤ 3`, or a non-API `domain`) where the stratum matters. Two gaps (G3, G8) cannot be fully tested on this corpus at all; I say so where it applies.

## 5. Hypotheses for the dataset pass (checklist)

Each line names the SCHEMA fields that falsify it. "All records" means the whole corpus; strata are given where the corpus bias matters. Before testing H1, H2, H6 and H7 (which rest on coder judgement), **double-code a 15% sample** of `chopinFit.shape` and `chopinFit.gaps`; if Cohen's κ < 0.6 on shape, treat the shape-based results as inconclusive.

- [ ] **H1. The four shapes miss a real share.** `chopinFit.shape ∈ {mixed, none}` in **≥15%** of all records. _Falsified if < 10%._
- [ ] **H2. Tune is rare; choice dominates.** `shape == choice` is the most frequent single value, and `shape == tune` is **≤10%** of all records (also report the `domain ∈ {ui-ux, product-behaviour}` stratum, where I expect tune to be higher). _Falsified if tune > 15% overall._
- [ ] **H3. Choices are small and criteria are mostly implicit.** Among choice-shaped records, median `options.length ≤ 3`, and `criteria` is non-empty in **≤50%**. _Falsified if median ≥ 4 or criteria present in > 70%._
- [ ] **H4. The first proposal usually wins (ratify is the modal act, G1).** In decided records with ≥2 options, `options[0].fate == chosen` in **≥60%**. _Requires collectors to list options in proposal order; drop records where `notes` says otherwise. Falsified if < 45%._
- [ ] **H5. Deferral is common enough to need a state (G2).** `process.deferred == true` in **≥15%** of all records, and among `outcome.decided == false`, deferred count **≥** `outcome.how == abandoned` count. _Falsified if deferred < 8%._
- [ ] **H6. Decisions don't stand alone (G4, G7).** Non-empty `process.subQuestions`, or a `chopinFit.gaps` entry coded _coupled / dependent / staged_, in **≥20%** of all records; for `sources[].kind ∈ {rfc, proposal}`, **≥40%**. _Falsified if < 10% overall._
- [ ] **H7. Evidence is needed beyond check (G6).** Among records with `chopinFit.shape ≠ check`, **≥30%** have `process.research ≠ none` or `process.spike ≠ none`. _Falsified if < 15%._
- [ ] **H8. Reversibility beats confidence (G5, over-build).** `outcome.reversibility ∈ {stated-easy, stated-hard}` in **≥25%** of decided records, and `outcome.confidence == stated` in **≤15%**. _Falsified if confidence is stated at least as often as reversibility._
- [ ] **H9. Dissent survives decisions (keep Takes on the record).** `outcome.dissent` non-null in **≥25%** of decided records with `participants.count ≥ 3`. _Falsified if < 10%._
- [ ] **H10. Decisions are revisited, and in-place Reopen is not always enough (G10).** `process.reopened || process.superseded` in **≥10%** of all records; of those, **≥30%** carry a gap coded _supersede / revert / migration_. _Falsified if reopened-or-superseded < 5%._
- [ ] **H11. Many debates happen on code that already decided something (G3 proxy).** `sources[].kind` includes `pr` **and** `process.spike == implementation-pr` in **≥20%** of all records. _Falsified if < 10%. A pass doesn't prove G3 for agents; a fail weakens it._
- [ ] **H12. Small groups decide by one person, not by vote (social-layer weighting).** In records with `participants.count ≤ 3`, `participants.decider` is a single person (named maintainer, BDFL or equivalent) in **≥75%**, and `process.poll == true` or `outcome.how == vote` in **≤10%** of _all_ non-standards-body records (exclude collector `tc39` and other committee collectors). _Falsified if votes or polls exceed 20% outside standards bodies._
