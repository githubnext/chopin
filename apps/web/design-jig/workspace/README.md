# Workspace sizing jig

Open <http://127.0.0.1:5181/design-jig/workspace/> with the web development server running.

The real resize handle and proposed composer run inside a local document/chat preview.
Chat starts at 500px, stays at least 250px, and can grow until the document reaches
450px. Resize the frame with Dial Kit to check that the preferred Chat width survives
temporary constraints. Below 700px, switch between Document and Chat with the tabs.
Drag the divider or focus it and use arrow keys, Shift+arrow, Home, or End.

Copy values exports preferred and rendered widths. This jig changes no production layout.
The [composer jig](../composer/README.md) covers composer states and interactions.
