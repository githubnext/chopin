# JEV-005 — Open Jev diagnostics explicitly from code icons

Status: Ready for Maggie’s review. PR: [#243](https://github.com/githubnext/chopin/pull/243). Reported as “Issue 4” by Maggie; JEV-004
already tracks the separate baseline CI timeouts. Stable ID: JEV-005.

## Problem and concrete reproduction

Hovering or scrolling across chat messages opens Jev analysis popovers. Hovering
an open decision opens its evidence/developer-information popover. These surfaces
interrupt ordinary reading. Code inspection confirms message mouseenter listeners
in `apps/web/src/conversation-plan/markers.tsx`; card evidence uses the shared
editor hover layer. This issue concerns interaction, not analysis correctness.

1. Open a document with analysed chat messages and an open Jev decision.
2. Move across messages, scroll the transcript, and hover the decision body.
3. Observe debug popovers opening without deliberate activation.

## Approved behavior and scope

Maggie requested small code/dev icon buttons. Chat gets one at the top-right of
each message with available diagnostics. Decisions get one immediately left of
“Show source in chat”. Clicking or keyboard-activating the code icon opens the
existing popover content. Hover, focus alone, message-body clicks and ordinary
scrolling do not open debugging popovers. Escape, close and outside click dismiss
an open panel; appropriate focus returns to the trigger. Explicit Review actions
continue to work. Source navigation, evidence contents and normal decision readers
retain their behavior. Icons use the existing shared button style and icon set.

Two approaches considered: reuse current popovers and replace triggers (chosen:
small change, preserves content), or introduce a separate diagnostics inspector
(more state and a new UI surface). The existing source icon is the visual reference;
Maggie described the end state directly and preapproved specs/plans.

Scope excludes anchor precedence (JEV-001), prose rationale (JEV-002), extraction
and recovery policy (JEV-003), and CI reliability (JEV-004). Keep the main design
system and shared decision renderer; do not restore the legacy Jev renderer.
