# JEV-007 — Remove inline Jev pills from chat messages

Status: Ready for Maggie’s review. PR: [#245](https://github.com/githubnext/chopin/pull/245). Reported as “Issue 6”; stable ID: JEV-007.

Maggie requested removal of the visible Jev labels beneath each chat message.
The current transcript is the reference; the approved end state has message text
without Question/Proposal/Reason/Support/etc. pills or the Review-excerpts pill.
Specs and routine choices are preapproved.

## Design and scope

Remove the inline card-link and Review-excerpts buttons from
`apps/web/src/conversation-plan/markers.tsx`. Keep analysis/evidence classification,
source metadata, retries, permission checks and card navigation. Move the existing
card-link controls into the analysis popover; excerpt correction already lives
there. Dropping the controls entirely was considered, but would lose navigation.
Remove unused summary-count code. Avoid new renderers or data changes.

This fix is based on `origin/Maggie/jev-chat-product` and targets that prototype,
which remains unchanged. PR #243 separately adds click-only code icons. Verify
compatibility with that change in a disposable combined fixture; do not merge or
copy its commits into this fix PR. Any overlapping-file integration must preserve
both behavior changes. The width change in PR #244 is independent.
