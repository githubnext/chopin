# JEV-006 — Widen the default chat pane by 60px

Status: Ready for Maggie’s review. PR: [#244](https://github.com/githubnext/chopin/pull/244). Reported as “Issue 5”; stable ID: JEV-006.

The chat pane is too narrow by default. Maggie requested about 60px more width.
The existing workspace is the reference; the approved end state is the same chat
surface with more horizontal space. Specs and routine choices are preapproved.

## Design and scope

Change `CHAT_PANE.initial` in `apps/web/src/workspace.tsx` from `304` to `364`.
Keep the existing `304–400` resize range, storage key, saved user widths, and
compact full-width chat behavior. This changes the default without overriding an
intentional size. Raising all three bounds was considered but would change more
than the requested default. No storage migration, new component or server change.
