# JEV-004 — Baseline CI conversation-capacity timeouts

Status: Queued. PR: Pending.

## Problem and evidence

Baseline `27eb3724a6e7ba3020552e7a1fa17f234811941b` passed the reported local suite
but failed validation in [GitHub Actions run 37060546539](https://github.com/githubnext/chopin/actions/runs/37060546539/job/111015834484).
The sanitized log at `/private/tmp/jev-baseline-validation.log` records 3,586 pass,
3 skip and 3 fail. All failures are approximately 20-second timeouts in
`apps/server/src/questions/conversation-capacity.test.ts`:

- `the last event slot is reserved for submit across restart`
- `the last event slot is reserved for cancel across restart`
- `ordinary asks and startup backfill preserve reserved mirror slots`

Container build passed according to the baseline handoff. Browser CI was still
running at that handoff; its eventual result is not established here. No root
cause is established.

preserving their assertions and domain guarantees. Diagnose the timeout source;
do not simply raise timeouts. Keep this fix separate from JEV-001 and other
product issues.
